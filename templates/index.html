System Features

Built with Python, Flask, scikit-learn & SimPy

No-Show Prediction

Random Forest ML model predicts patient no-show probability using 8 features including history, distance, and appointment timing.

Smart Slot Allocation

Priority-weighted greedy algorithm assigns appointments based on urgency, wait time, and predicted attendance probability.

SimPy Simulation

Discrete-event simulation compares baseline vs AI-optimized scheduling across KPIs: utilization rate, wait time, and throughput.

Overbooking Strategy

High-risk patients are flagged for intelligent overbooking, ensuring slots are filled even when no-shows occur.

Real-time Risk Alerts

Each appointment shows a LOW / MEDIUM / HIGH no-show risk badge, allowing admins to take proactive action.

SQLite Database

Fully relational database with patients, doctors, time slots, and appointments managed via SQLAlchemy ORM.
